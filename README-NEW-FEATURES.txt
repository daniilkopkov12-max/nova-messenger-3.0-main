Nova Messenger — сборка с дополнительными функциями

В этой версии добавлены:
- редактирование своих текстовых сообщений через PATCH /api/messages/:id;
- удаление своих сообщений через DELETE /api/messages/:id;
- переключатель «Одноразовое» в композере (автоудаление из текущего клиента через 10 секунд; это пока не серверный режим с синхронизацией на всех устройствах);
- выбор основного акцентного цвета в настройках;
- обои текущего чата по URL;
- префиксы ВЛАДЕЛЕЦ для @okak и МОДЕРАТОР для @sladkiy;
- аватар собеседника в голосовом звонке;
- перетаскивание мини-окна звонка;
- анимации сообщений и нажатий;
- живой предпросмотр видеокружка во время записи.

Установка:
1. Сделайте резервную копию своей папки проекта и базы данных.
2. Распакуйте содержимое ZIP поверх проекта с заменой файлов.
3. Не заменяйте свой .env, базу данных и папку uploads.
4. В корне проекта выполните: npm install
5. Затем выполните: npm run build
6. Запустите привычным способом: npm run dev

Примечания:
- Обои и цвет сохраняются в localStorage этого браузера.
- Одноразовый режим в этой сборке удаляет сообщение через 10 секунд только из текущего клиента и не является защищённым исчезающим сообщением на сервере.
- Удаление чатов целиком ещё не реализовано в этой сборке.
