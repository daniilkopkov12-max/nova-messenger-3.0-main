Nova Messenger — обновление темы, шапки чата, настроек и модерации

Включено:
- улучшенная читаемость тёмной темы;
- мобильные ограничения ширины;
- закреплённая шапка чата (шапка находится отдельно от прокручиваемой области сообщений);
- вкладка настроек с переключением темы и списком локальных блокировок;
- локальная блокировка собеседника в этом браузере;
- серверная модерация: @okak — владелец, @sladkiy — модератор; блокировка аккаунта проверяется сервером.

Установка: остановите npm run dev, распакуйте ZIP в корень проекта с заменой файлов, затем npm run build и npm run dev. Не заменяйте свой .env и базу данных.

Важно: блокировка собеседника хранится в localStorage этого браузера. Бан аккаунта хранится в поле User.status существующей SQLite-базы. Убедитесь, что аккаунты действительно называются okak и sladkiy (без учёта регистра).
