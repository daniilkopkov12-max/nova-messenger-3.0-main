# Nova Messenger — исправление звонков v2

Этот архив содержит только файлы, которые нужно добавить/заменить в существующем проекте. В архиве нет `.env`, базы данных, `node_modules` или загруженных файлов.

## 1. Установка патча

1. Остановите `npm run dev` в окне приложения через `Ctrl+C`.
2. Распакуйте содержимое архива в корневую папку проекта, где лежат основной `package.json`, `frontend` и `backend`:
   `C:\Users\Windows\Downloads\nova-messenger\nova-messenger`
3. Подтвердите замену файлов.
4. Запустите снова из корневой папки:

   ```bat
   npm run dev
   ```

5. Оставьте `cloudflared` во втором окне запущенным.

## 2. Что исправлено

- Удалённые аудио- и видеодорожки складываются в один устойчивый MediaStream; элементы воспроизведения больше не переключаются между отдельными потоками каждого трека.
- Добавлена повторная попытка воспроизведения, когда удалённая дорожка перестаёт быть muted.
- В окне звонка показываются состояние WebRTC, состояние ICE, локальные дорожки, полученные дорожки и информация, настроен ли TURN.
- Добавлен защищённый `GET /api/webrtc/ice-servers`: браузер получает короткоживущие TURN-данные, а постоянный токен API остаётся только на сервере.
- Сохранена совместимость с обычным TURN-сервером через `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL` в корневом `.env`.

## 3. Важно: для звонков между разными сетями нужен TURN

Без TURN проект пробует STUN-серверы. STUN сам не ретранслирует медиа, поэтому некоторые пары сетей/роутеров не смогут соединиться.

### Вариант A: Cloudflare Realtime TURN

1. В Cloudflare создай TURN key и отдельный API Token с разрешением Calls Write. Следуй официальной инструкции: https://developers.cloudflare.com/realtime/turn/generate-credentials/
2. В корневом `.env` (НЕ во `frontend/.env` и НЕ с префиксом `VITE_`) добавь значения:

   ```env
   CLOUDFLARE_TURN_KEY_ID=UID_ТВОЕГО_TURN_KEY
   CLOUDFLARE_TURN_API_TOKEN=ТВОЙ_API_TOKEN
   ```

3. Сохрани `.env` и перезапусти `npm run dev`. Открой новый звонок.
4. Если в строке диагностики всё ещё написано «TURN не настроен» или «Не удалось загрузить TURN», проверь, что переменные лежат именно в корневом `.env`, ID и токен правильные.

**Никому не отправляй API Token и не помещай его в публичный GitHub.** Браузер получает лишь временные TURN-учётные данные для звонка.

У Cloudflare Realtime TURN есть бесплатная квота 1 000 GB в месяц, после неё указана цена $0.05 за GB исходящего трафика. Если нужна гарантия нулевой оплаты, не включай платное использование/перерасход и проверь условия тарифа перед активацией: https://developers.cloudflare.com/realtime/turn/faq/ . Если сервис просит платёжные данные или включение оплаты, попроси родителя/опекуна помочь с аккаунтом и настройками биллинга.

### Вариант B: другой TURN-провайдер

Добавь в корневой `.env`:

```env
TURN_URL=turn:твой-сервер:3478?transport=udp,turns:твой-сервер:5349?transport=tcp
TURN_USERNAME=временный-логин
TURN_CREDENTIAL=временный-пароль
```

Указывай только реальные данные провайдера; пример выше не является работающим сервером.

## 4. Как понять результат

В окне звонка теперь показывается диагностика:

- `ICE: connected` / `completed` — сетевой маршрут найден.
- `ICE: failed` — устройства не нашли рабочий маршрут; настрой TURN.
- `От собеседника: дорожек пока нет` — браузер ещё не получил медиа-дорожки.
- `От собеседника: audio:live, video:live` — дорожки приходят; если звука нет, нажми «Включить звук собеседника» и проверь выход звука/громкость браузера.

Если после настройки TURN не заработает, сообщи текст строк `WebRTC`, `ICE`, `Локально`, `От собеседника` из окна звонка. Не присылай `.env`, токены, cookies или пароли.
