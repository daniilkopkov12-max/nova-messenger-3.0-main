# Безопасность Nova Messenger

## Реализовано

- Пароли: Argon2id
- Сессии: случайный токен, httpOnly cookie, срок 30 дней
- Валидация всех входов (Zod)
- Rate limit на register/login
- Helmet
- CORS с credentials только для FRONTEND_URL
- Проверка членства в чате перед чтением/записью сообщений
- Проверка владельца сообщения перед edit/delete
- Секреты только в `.env` (не в frontend)

## Рекомендации для production

- Сменить SESSION_SECRET и JWT_SECRET
- Использовать PostgreSQL
- HTTPS везде
- Content-Security-Policy настроить жёстче
- Ограничить размер загружаемых файлов и проверять MIME
- Регулярные бэкапы БД
- Не публиковать `.env`
- TURN с аутентификацией
- Рассмотреть refresh-токены и отзыв сессий

## Что НЕ заявлено

Сквозное шифрование (E2EE) **не** реализовано. Сообщения хранятся на сервере в открытом виде (как в классических веб-мессенджерах без E2EE).
